## 新增原始证据

Karuppiah等，2024，Scientific Reports，PMID39500929，DOI[10.1038/s41598-024-75140-7](https://doi.org/10.1038/s41598-024-75140-7)。原文Methods确认：25°C、Biacore T200、约1000RU生物素化pHLA固定在streptavidin/CM5表面、可溶TCR进样、PBS/P20、10µL/min、同一表面三次重复进样、单结合位点平衡拟合。重复进样不是三次独立生物学重复。

肽为ELFSYLIEK，MHC为未突变HLA-A*03:01/A*11:01。排除论文中的突变／嵌合HLA列。采用表格精确值，不采用正文四舍五入值或曲线目测值。

| 受体构建体 | A03 Kd/µM | A11 Kd/µM | 谱系与序列证据 |
|---|---:|---:|---|
| S2-198 | 0.076 | 1.227 | S2；序列SI与8RYO两条完整蛋白链逐字一致 |
| S8-WT | 43.95 | 285.9 | S8；序列SI与8RYP一致；A11仅敏感性分析 |
| S8-9F3 | 7.46 | 14.48 | S8；序列SI与8RYQ一致 |
| S8-W96 | 52.17 | 89.71 | S8；原文SI明确完整α链及S8共用β链，不从基因名补序列 |

S8-WT/A11的285.9µM拟合值超过Methods所述250µM浓度上限，且未证明饱和：保留为发表的拟合观察，不作为主指标中的可靠精确靶值。没有把它改写成某个阈值或“阴性”。无数值误差的测量仍留null，不伪造误差。S2-198/S8-9F3/S8-W96是工程变体；“WT”仅指该文的亲本，不证明来源于同一供体的天然配对。不得把这些数据称为自然人群随机样本。

S2/S8共享TRAV21，β分别为TRBV6-6/TRBV9（发现用TCR3d注释；身份由原始完整配对序列核实）。这是两个新的序列谱系，**不是两个全新的αV家族，也不声称训练/测试V基因集合完全不相交**。

## 独立性与泄漏防护

沿用现有`reserved_hits`规则：任一链的同源序列＋CDR3近邻即保守排除。逐条核对旧91条亲和力记录、临床保留集和全部历史结构v1–v7，没有这些训练／历史结构家族命中。`family_audit.json`保留完整结果；部分受体与IMMREP25的既有**保留元数据**命中如实列出，不冒充此前从未在任何数据库出现，也不能转入训练。

论文数量不能替代来源独立性：PIK3CA论文与T4H2/SILv44论文共享Baker及SPR研究贡献，合并为同一来源组，修正此前将旧7条计作3组的过度计数（实际2组）。加入Immunocore后才得到3组。采用完整姓氏＋首字母作者标识、变音符归一化及ORCID交叉核对做保守筛查，并核查机构／实验贡献；这是一种可审计的来源隔离代理，不是所有实验室之间绝对独立的证明。所有保留开发论文与测试论文之间均无该代理下的共同作者；开发／测试也没有≥0.8的肽序列相似命中。对同名歧义保守排除，不通过猜测恢复样本。

不改变旧切分：来源重复的C25/C7、HCV1406、F50、GVY01、LLL8及验证中的Q04/CLB相关记录按实际条目列入8条排除清单（以JSON逐条记录为准）。未来任何新模型只允许读取新开发配方，临床集及全部已知验收家族保留。全局训练入口已追加新受体保留登记，不能经旧入口把S2/S8混回训练。

## 验收协议

1. 只用开发子集选特征、拟合归一化和超参数；锁定模型／代码／数据SHA后再做测试，严禁用新测试分数决定保留哪些测量。
2. 报告pKD MAE/RMSE与训练均值基线；主指标14条，完整15条单列敏感性分析；按来源和受体谱系报告，保留不同方向、不同研究的测量，不把T4H2的1.8和6.8µM平均成一个“金标准”。
3. 同来源、同受体工程变体、同表面重复进样均相关；来源内按谱系汇总，再对来源等权；做逐来源排除敏感性分析。只有3个来源组，不能给出精确人群泛化置信区间。
4. 不能由本集得到真实结合二分类AUROC、临床风险、安全阈值或人群有效性。HLA-E双特异性格式和PAP固定四聚体仍单独隔离。

这完成的是可审计的数据冻结；没有自动放行旧模型或开跑重训。下一次训练应生成绑定本冻结及新开发配方的新release，不能只在旧release上把`training_allowed`改为true。

## 本轮仍隔离的实质问题

- **S2-WT**：序列SI写DSAIRYNL，比8RYM的DSAIYNL多一个R。不能猜删R；其WT测量不进集。S2-198本身有直接测量及完全一致的SI/PDB序列，独立按该工程构建体核实。
- **FTS TCRpub/TCRpriv**：新发表文章37°C SPR与完整序列齐全，但Fig2图内标签和图注的7.2/9.7µM对应相反；Source Data内部TCR19/TCR3未提供完整明确别名对照。原图、Source Data、审稿文件全部保存；不凭拟合结果替作者改标签。
- **AS8.4、Q04、CLB、302TIL**：新PDB／新文章不能掩盖已有结构家族或旧亲和力记录暴露，排除新增验收计数。
- **C4/α7β2新论文**：仍是临床保留／旧测试受体，不是新受体；>150µM仍是删失值。
- **TCR156**：Methods固定pMHC四聚体，不能悄悄当单体；继续单独保留。
- **TW10 D1/D6完整变量区、剩余10条原文测量条件、2条精确表值、2条温度、临床实际工程DNA批次对应**：本轮没有可靠新证据，原有隔离和缺口清单不变，不填默认值。
