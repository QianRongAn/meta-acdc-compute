## 原始输入与不补缺约束

来源：[ENA SRR34543498](https://www.ebi.ac.uk/ena/browser/view/SRR34543498)、[GEO GSM9108725](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM9108725)。ENA 两个完整 gzip 文件应分别为 3,122,244,336 和 3,154,927,322 字节；本轮仅取得每个文件前 33,554,432 压缩字节，HTTP 206 的范围和 SHA256 见 `prefix_downloads.json`。它们不是完整 gzip，也没有通过整文件 MD5。

两份前缀分别包含 546,555 和 550,977 条完整 FASTQ 记录；仅使用同步的 546,555 对，另外 4,422 条单端前缀尾部记录不参加分析，残缺终末记录丢弃。92 条码白名单只提供细胞身份，不提供生物序列。条码和 UMI 必须精确且 Q≥20；去除 R1 前26个技术碱基，仅修剪两端低质量碱基，最短60 nt。得到20,031对 reads、覆盖92条码。没有条码纠错、参考序列填补、替换碱基或用构建体引导组装。

预先按筛选后的读段数选定三个细胞：TAAACCGAGGGAAACA（413对）、CACACAATCTAACCGA（409对）、AGGCCACGTATAGTAG（396对）；未按组装成功与否挑选。固定 RNA SPAdes 3.15.5、2线程、4 GB、仅组装、不做读段纠错。三个单细胞组装都检出同一对 CDR3；池化组装49条转录本仅检出β，**池化组装失败于α，不作为完整配对重建依据**。

α在蛋白层面仍无法区分TRAV7-3*04、TRAV7D-3*01、TRAV7D-3*03；天然核苷酸框架在本次固定参考集合中只匹配TRAV7D-3*03。不能据此声称完成基因组位点定相。β的近似HMM J调用TRBJ2-4*01仍保存原样；完整天然J核苷酸精确支持TRBJ1-6*01，不能由“productive”来源标志把参考ORF改为F。

精确观察到的V参考前缀范围（变量区0起、右端不含）：α[0,272)，β[0,287)；完整J参考范围：α[274,334)，β[296,349)。两条J片段都越过编号区间末端一个核苷酸。这些是**参考精确匹配范围，不是已经唯一确定的生物重排切点**；V删除、D/N来源及微同源分配仍未解。
