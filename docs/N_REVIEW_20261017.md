# N1–N14 审查复核（2026-10-17）

结论：多项批评命中当前缺陷，不能沿用之前“代码修好即可重训”的结论。本轮撤销旧结构 v4 的当前训练放行，保留全部原始文件与历史记录。修复代码不等于补齐生物学证据。

## 额外发现与五个待查项

1. 主 EGNN 肽标志第 24 列目前正确，但 hybrid 仍使用第 4 列，one-hot 切片也错；已修复并共享 feature_schema，跨字典氨基酸顺序显式重映射。hybrid 原批次归一与随机旧切分一起改为主入口的逐图处理、冻结 release/fold、拒绝覆盖 checkpoint。
2. 固定预算边界与概率对照实现可验证，不等于 EIG 优势仍存在。拒绝在伪 oracle 上回答这个经验问题；已消耗外部功能集不得反复调参。
3. 两篇 manuscript 活跃正文不再陈列肯定式旧性能结果，原稿归档。
4. benchmarks 和 benchmark-report 同样处理；仪表盘硬编码 STABLE／“扩样单调”一并撤下，历史分数标记撤回。
5. 审查时当前仓库实际有 5 个测试文件、85 项测试，非 1 文件 16 项。本轮增加专门回归文件，覆盖聚类传递性、unseen-both 两侧隔离、IEDB 单位边界、全种子核算、缺失原子、显式置信度、混合模型列与批次一致性。测试通过不证明生物学结论正确。

## 重训重新放行条件

1. 新版本从源结构重建，逐条保存通过／拒收理由，不覆盖旧数组；保留已有受体家族及测试集归属，过滤不能触发重新洗牌。
2. 对位移和嫁接控制重新设计并独立评估构造伪影。筛查阈值是预设工程检查，不得按测试 AUROC 反向调整。
3. 新版本独立验收完整原子、源链、身份、同复合物／受体家族、外部保留、特征 schema、坐标／mask 和冻结来源哈希。
4. 用真实终点训练时，结构输入对阳性／非阳性使用统一生成和 QC；没有结构匹配的实验记录不能硬塞成结构图标签。
5. 当前没有新结构 release 获准训练；未运行 optimizer、未启动新看门狗／定时任务。hy4 按用户要求暂不使用。

科学依据：[VDJdb 原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5753233/)明确区分 confidence 与结合标签；[EGNN 原论文](https://proceedings.mlr.press/v139/satorras21a.html)提供等变架构，不证明本任务优于固定坐标消息传递；[MHC 呈递阈值原始实验](https://pubmed.ncbi.nlm.nih.gov/10426278/)不能替代当前预筛器的全池召回验证。
