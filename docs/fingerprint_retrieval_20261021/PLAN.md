# STRUCT-FINGERPRINT-20261021 预注册

**任务类型**：结构表征质量基准（representation-quality benchmark）。
**不构成**：结合／非结合预测、亲和力回归、临床风险、任何已撤回历史结论的恢复。

## 背景与动机

外部审查与两轮修复后的共识：结构模型的全部定量结论已撤回，重训结合分类仍缺真实阴性。
但一个不依赖结合标签、标签完全可核验的正面结果尚可重建——**结构是否编码受体身份**。
若修复后的管线训练出的表征能在家族外（未见受体）条件下从 100+ 受体中检索出同一受体的
其他结构，即证明模型学到的是真实结构内容而非构造伪影；这是任何下游使用的前提性证据。

## 输入（逐字节可复现）

- `native_inventory_graphs.pt`（168 张无标签天然图，来自 v7 release
  `20261017-structural-v7-atomic-repair`，置信度屏蔽、原子筛查通过、身份已核验）。
- `data/raw/af3_predictions/*_model_0.cif`（188 份打分候选）中，链 A/B 序列对与
  `af3_pending_upload` 角色头 FASTA 的 (alpha,beta) 精确匹配者才入池（预计 179 份）；
  未匹配者排除并记录。候选图以与 v7 相同的管线重建：`parse_cif(confidence_kind=af3_plddt)`
  → 屏蔽置信度 → `annotate_prediction`（参考序列来自 pending 面板）→ 界面图。
- 按图输入哈希去重；重复记录入册。

## 标签（可核验、非实验）

- `receptor_id` = 精确 (alpha,beta) 序列对（sha256）。受体身份是元数据，不涉及结合主张。
- `family_id` = v7 `structure_records.json` 的 family 字段（能匹配到 v7 记录时）；候选独有受体
  以自身为家族（保守，等同最严格的家族外评估）。

## 任务与协议

- 划分：按 family 分组的 5 折交叉验证（分组 KFold，`n_splits=5, seed=20261021, shuffle=True`），
  同一家族绝不跨训练／测试；折分配在训练前落盘。
- 模型：EGNN（6 层、hidden 128、特征 26/16，与现有打分路径同构）+ 投影头（128→64，LayerNorm）。
- 目标：有监督对比（SupCon），正样本 = 同 `receptor_id`；温度 0.1；Adam lr 1e-3；60 epoch；
  batch 16；设备 cuda，不可用则 cpu。仅训练折参与训练；不早停于测试折。
- 任务 A（主）：受体检索。查询 = 测试折每张图；画廊 = 全部其余图。正确 = 余弦最近邻与查询同
  `receptor_id`。指标：rank-1 命中率（宏观）、平均倒数排名 MRR、同/异受体对的 AUROC。
  机会水平按各折画廊的受体构成逐查询计算后平均。
- 任务 B（次）：家族分类。k=1,3,5 近邻投票，宏观 top-1 准确率 vs 训练折家族构成的机会水平。
- 任务 C（诊断，不作结论）：域分类（crystal/predicted）最近质心准确率——若高，说明表征仍携带
  域签名（置信度屏蔽的泄漏检查），只作诊断记录。

## 预注册成功标准（训练前固定，不据结果调整）

1. 任务 A 宏观 rank-1 ≥ 2× 机会水平，且同/异 AUROC ≥ 0.9；
2. 任务 B 宏观 top-1 ≥ 2× 机会水平；
3. 5 折全部可复现（同 seed 重跑数字一致）。

任一不满足即如实报告为阴性，不得改协议换口径。

## 范围与禁止

- 禁止：调整阈值/特征/损失以抬高指标；把候选评分、旧种子表或任何撤回数字并入本任务；
  声称结合预测能力；使用保留家族（`assert_reserved_absent`）训练。
- 记录：全部输入哈希、折分配、训练日志、权重、逐查询预测与评估 JSON 落盘。
