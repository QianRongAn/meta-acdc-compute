# FOLLOWUP-AUROC-RASHOMON-20261021 预注册

**任务类型**：表征质量基准的后续实验（representation-quality follow-up）。
**不构成**：结合／非结合预测、亲和力回归、临床风险、任何已撤回历史结论的恢复。
**上游**：`STRUCT-FINGERPRINT-20261021`（docs/fingerprint_retrieval_20261021/PLAN.md，
本目录 README.md）。本实验在其之上做两件事：

1. **收紧同/异 AUROC 差距**（上游 0.767 vs 自设门槛 0.9，且上游表征近乎坍缩）；
2. **对新的表征做 Rashomon（跨实例稳定性）分析**——按 SOP"任何 OOD 打分结论必须过
   跨实例稳定性检验(Rashomon 效应)"，重建已撤回的 0.644 排名稳定性的诚实版。

## 背景：训练前诊断（只读已有产物，无新训练）

用已提交的 5 个折模型重新嵌入 331 张图（`scripts/diagnose_auroc_gap.py`，
产物 `auroc_gap_diagnosis.json`）：

| 发现 | 数值 |
|---|---|
| 全体图两两余弦相似度区间 | [0.9957, 1.0000]（宽度 4e-3） |
| 同家族对 AUROC（折均值） | ≈ 0.52（机会水平 0.5） |
| 折 AUROC 重嵌入不稳定性 | 同一权重重新嵌入 ±0.01–0.02 |
| 跨家族对 | 全部为负样本（receptor→family 一致），AUROC 无定义 |

结论：上游 0.767 是坍缩表征上 4e-3 相似度带宽内的微弱排序差，且指标自身对浮点
重嵌入不稳定。**收紧 AUROC 差距 = 展开表征 + 分离同家族不同受体**，两者是一件事。

## 改进配方（v2，与 v1 的差异逐项列明，其余全部保持一致）

不变的部分：EGNN 6 层 hidden 128；节点/边特征 26/16（同打分路径 schema）；不变变体
（坐标更新关闭，v1 的正式模式）；按家族分组 5 折（seed 20261021，折分配沿用 v1 落盘
文件）；任务 A/B/C 与全部指标定义；dropout 0.1；梯度裁剪 10；Adam 基础 lr 3e-4、
wd 1e-4；确定性设置（cudnn.deterministic）。

| 项 | v1 | v2 | 理由 |
|---|---|---|---|
| batch size | 16 | 64 | 每锚点负样本数 4×：SupCon 分母质量，展开空间的主杠杆 |
| 投影头尾层 | LayerNorm(64) | 无 LayerNorm，损失与评估前单位球归一化 | LN 零中心化把嵌入压进超平面，促成坍缩；标准 SupCon 不这么做 |
| 温度 | 0.1 | 0.07 | 更硬的判别 |
| 嵌入维度 | 64 | 128（头 385→256→128） | 展开后的容量 |
| epoch 数 | 60（恒定 lr） | 120，余弦退火（warmup 5，lr 3e-4→3e-6） | 收敛 |
| 难负样本 | 无 | 同家族不同受体负样本在分母中权重 ×(1+λ)，λ=1.0 | 直接针对诊断发现的同家族混淆 |

## 预注册成功标准（训练前固定，不据结果调整）

1. 池化同/异 AUROC ≥ 0.9（沿用上游未达门槛）；
2. 检索 rank-1 ≥ 2× 机会水平（上游预注册标准，防检索回归）；
3. 表征展开门槛：全体图两两余弦相似度中位数 ≤ 0.95（坍缩修复的必要条件）；
4. 域诊断（任务 C）准确率 ≤ 0.6（泄漏检查）；
5. 同 seed 确定性：至少 1 个折重跑数字一致。

任一不满足即如实报告为阴性。

## Rashomon 协议（跨实例稳定性，描述性报告，无 pass/fail 条）

- Rashomon 集合：每个折训练 3 个实例（同一配方、同一折划分，仅初始化/打乱种子不同：
  seed ∈ {20261021, 1101, 4242}）。seed 20261021 的 5 折同时是主结果。
- 每个实例落盘：全部 331 图的嵌入（单位球）、两两相似度矩阵、逐查询检索排序列表。
- 指标（每折计算、跨折池化，配对统计 ±95% CI）：
  1. 性能带（performance band）：三实例 AUROC / rank-1 的 min–max；
  2. 排名稳定性：逐查询画廊相似度排序在三实例对之间的 Spearman ρ（已撤回 0.644 的诚实重建）；
  3. 检索一致性：rank-1 命中一致率、top-5/top-10 平均 Jaccard；
  4. 判决翻转率：在池化中位阈值下，(查询, 其他) 对在三实例间的同/异判决翻转比例；
  5. 嵌入一致率：同一图在三实例间两两余弦均值 vs 跨图基线；
  6. 池化 AUROC：三实例相似度取均值后的 AUROC（描述性，不作门槛）。
