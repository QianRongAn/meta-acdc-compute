## 解释范围（重要）

- 阳性发现：**审计修复后的管线训练出的结构表征，能在家族外（未见受体）条件下，
  以 13× 机会水平的 rank-1 检索出同一受体的其他结构**（226 个查询、5 折一致）。
  这说明表征承载真实结构内容（受体身份），而不是构造伪影或域签名。
- 这不是结合预测：受体身份 ≠ 结合标签。它只证明"结构 → 受体身份"这条信息通道
  已在修复后的管线中打通——下游任何结合/脱靶应用的必要前提。
- AUROC 0.767 说明同一家族内的不同受体在表征中仍有混淆——正是后续工作的靶点。
