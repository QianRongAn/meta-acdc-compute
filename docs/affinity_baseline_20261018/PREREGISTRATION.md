# 亲和力回归基线：训练前注册

这是新的研究用release `20261018-affinity-source-disjoint-v2`，不修改旧affinity-v8或任何历史冻结文件。采用新开发配方：训练10条/5块，验证10条/5块；新测试15条（主指标14条），4个连通块、7个谱系、3个来源组。允许的是可溶人αβ TCR–经典MHC-I SPR pKD回归，不是EGNN重训、结合二分类或临床风险模型放行。

本文件、代码和完整training_release在任何真实模型拟合或测试访问之前提交到Git，构成预注册时间顺序证据。`training_release/plan.json`为具体机器协议；父冻结的training_allowed=false和未打分字段是当时快照，不改写为本轮运行状态。

- 特征复用已有baseline的α/β/肽1–2mer频率、长度、氨基酸组成交互、MHC、原文核实的仪器及温度；DictVectorizer只拟合训练数据，未知验证／测试类别忽略。
- Ridge固定alpha=1,10,100，SVD求解；训练按原连通块等权；验证按原连通块等权RMSE选择，精确同分选较小alpha。不把验证集并回训练，不试其他模型／网格。
- 比较基线为训练连通块等权pKD均值。pKD=6-log10(Kd/µM)，不是结合概率。
- 训练进程只解码开发JSON。父冻结及原始来源只做完整性哈希，不生成测试特征或测试预测。输出模型、验证预测、环境、候选验证指标，再输出model_lock.json。
- 独立验收进程必须先验证锁定模型与release摘要，复算验证指标和训练均值，再独占写入持久测试访问登记，之后才读取冻结测试JSON。验收进程不调用fit，不调整模型。
- 主指标14条；S8WT/A11的285.9µM只进入15条敏感性分析。测试先按来源等权，来源内按谱系等权，再按谱系内观察等权；逐来源、谱系、论文和固定方向分别展示。
- 预先规定探索性性能通过条件：主指标RMSE和MAE都严格低于训练均值基线，且三次逐来源排除的指标子集中RMSE均更低。逐来源排除只是固定预测上的指标敏感性分析，不重训。只有3来源，不给出精确人群CI或显著性结论。
- 性能不通过也照实提交，不基于测试结果重新选参。全局fit/test独占登记阻止重复派发、覆盖与测试后继续拟合本配方；崩溃痕迹保留。未来开发需要新协议和额外未暴露验收数据。

全部第三方原件仍在本地data/external_evidence，已有URL、定位及SHA；本目录发布足以重建新训练release的20条开发数据、协议及manifest，以及后续锁定模型和验收结果。临床保留集始终不参与训练。
