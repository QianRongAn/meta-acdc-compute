## 如何解释

- 主测试RMSE仅下降0.007417 pKD（相对约0.74%），MAE仅下降0.004486。这只支持本次预注册探索比较略优于常数，不能支持实用优势。
- 主测试预测范围仅5.0816–5.1571，实际测量范围3.6778–7.1192。模型对受体／肽差异的响应明显压缩，接近常数预测；这比单看通过标志更值得重视。
- Baker和Immunocore来源的MAE略变差；排除Wu来源后的MAE也略变差。预注册规则只要求这些子集的RMSE改善，不能据此声称所有来源、所有指标一致改善。
- 测试有14条主观察，但只有7谱系、4连通块、3来源组；S2/S8工程变体不算独立受体复本。数据是特定可溶构建体、特定方向、温度和拟合模型下的SPR观察，不是统一绝对金标准。
- 仍无真实阴性结合分类结果、无完整临床受体结局验证，也没有修复后结构EGNN训练结果。原始数据和旧模型没有被本轮覆盖。

**本轮完成的是研究基线的完整训练与验收，不是亲和力模型的广泛有效性放行。** 后续可预注册更适合小样本的表征／外部预训练对照，并补充新的未暴露来源与受体；本冻结测试已经使用，不能依它继续调参。没有启动任何后续训练或10分钟调度。
