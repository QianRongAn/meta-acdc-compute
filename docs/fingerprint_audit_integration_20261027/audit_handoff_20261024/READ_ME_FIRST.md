## 15例训练标签置换的结果

5折×3种子；先在查询内平均种子，再家族等权。

| 指标 | 真实标签 | 训练标签置换 |
|---|---:|---:|
| 全部负样本 AUROC | 0.9379 | 0.7368 |
| 同家族困难 AUROC | 0.4385 | 0.4280 |
| 全画廊排名 Spearman | 0.4036 [0.3672,0.4411] | 0.2690 [0.2454,0.2927] |
| 同家族排名 Spearman | 0.4177 [0.2412,0.5936] | 0.1097 [-0.0545,0.2440] |

困难 AUROC 真实减置换 +0.0106，95%条件区间 [-0.0902,0.1071]，没有建立监督增益，也不能证明等效。两组排名稳定性点估计存在差别；不能由困难 AUROC 接近推导出稳定性指标完全无区分力。稳定性本身不等于有效性，更不能证明结构超出组成的增益。

区间条件于固定模型和画廊，按家族重采样，不覆盖训练与来源总体不确定性。每折仅3次置换，不提供校准的置换p值。旧0.946不得作为修复后结果引用。

## Procrustes

当前 scripts/rashomon_fingerprint.py 在 embs[s][train_idx].T @ ref[train_idx] 上做SVD，只使用训练折拟合；测试查询用于评价，并输出 fit_graph_indices / evaluation_graph_indices。附有当前源码。

但历史 docs/fingerprint_retrieval_20261021/followup/rashomon_results.json 仍写明 full embedding matrix 拟合。本次没有重跑历史对齐产物，因此“代码已修复”不能写成“历史结果已按修复方案重算”。上述新排名Spearman来自 retrain_evaluation.json；它比较每个实例内部的余弦排名，无需跨实例坐标对齐。

## 身份修正后的评估并非干净泄漏对照

46/331图通过当轮身份准入，但实际新开发池只有25张晶体图；困难评估只有2个组、8个可定义查询。参考模型0.4861，保留身份one-hot模型0.5000，标签打乱0.6667，组成和图大小均1.0000。全部阳性来自同PDB晶体副本、全部负对跨PDB，来源与标签完全混淆，不能把这些结果当作真正跨来源泛化证据，亦不能把两轮数字之差归因于去泄漏。

后续跨来源核验尚无同时满足来源平衡、困难对照及原子QC的评估单元；未启动新训练。cross_source_README.md 包含详情。旧285隔离项补足1项身份对应后，仍284项隔离；新增项只是同PDB副本，未自动纳入训练。
