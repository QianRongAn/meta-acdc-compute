# Paper 3 大纲：审计重建后的第一个可验证正面结果

> 状态：大纲（2026-10-21）。数字待 fingerprint 训练完成后填入。
> 本稿不恢复任何已撤回数字；结合预测与临床结论不在本文范围内。

## 候选标题

- "Receptor fingerprinting from TCR–pMHC structure: a pre-registered benchmark after a full external audit"
- 或："What survives an audit: structure-derived receptor identity as the first verifiable positive result of a TCR–pMHC modeling pipeline"

## 1. Introduction

- TCR 脱靶风险问题；结构建模的动机（序列方法难以捕捉几何/化学相容性）。
- 我们此前的管线经两轮外部审计（28 项 + 39 项清单）发现输入编码、切分、QC、
  临床身份等缺陷，全部定量结论撤回——诚实记录但无可引用结果。
- 本文目标：在审计重建后的管线上，回答一个**不依赖结合标签**的基础问题——
  "界面结构是否编码受体身份"。这是任何下游结合/脱靶应用的必要前提。
- 贡献：①审计重建后的可验证正面结果（受体检索/家族分类）；②预注册协议与
  家族分层评估；③同一数据上已发表工具（ERGO-I）的对照（阴性）；④可复用的
  身份核验与 QC 方法论。

## 2. 审计与重建（方法一）

- 外部审查发现的缺陷类别（残基编码、池化列、切分、QC 闸门、身份替换）与修复。
- 数据完整性护栏：逐字节哈希、release 指纹、构造筛查、清单护栏。
- 全部历史数字的撤回与取证（五种子重放 938/940、面板 347/98/45/11 核验）——
  证明重建基线的可追溯性。

## 3. 数据：经过身份核验的结构语料（方法二）

- 168 张天然界面图（v7 无标签资料库：145 晶体 + 23 预测；原子筛查、置信度屏蔽）。
- 163 张打分候选图：链 A/B 序列与角色头 FASTA 参考精确匹配才入池（179/188 匹配，
  16 份因身份/图构建失败排除）。
- 统计：331 图 / 160 受体 / 110 家族 / 55 受体 ≥2 结构（最多 11）/ 肽长 8–13。
- 标签是**元数据**（受体身份），不是实验结合标签——本文不声称结合预测。

## 4. 方法三：预注册的指纹基准

- 模型：EGNN（6 层, hidden 128, 特征 26/16）+ 投影头；SupCon 对比目标（正=同受体）。
- 划分：按家族的 5 折分组 CV（同一家族不跨训练/测试）。
- 任务 A（主）：受体检索（rank-1/MRR/同异 AUROC，逐查询机会水平）。
- 任务 B：家族 k-NN 分类（k=1/3/5，top-1 与机会比较）。
- 任务 C（诊断）：域分类（晶体/预测）——置信度屏蔽的泄漏检查。
- 预注册（PLAN.md/plan.json）与成功标准先行；结果原样报告。

## 6. 诚实阴性（对照）

- ERGO-I 官方权重在同一 10,000 条 MIRA 功能观测上的关联对照：
  逐肽宏平均 AUROC 0.5112 vs 基线 0.5001（两者均近机会）——序列基线在此功能
  终点上不携带预测信息；本文的结构表征是否提供额外信息，取决于 §5 的结果。
- 亲和力回归的零结果（近常数预测）一句话带过，指向结合标签的缺失。

## 7. Discussion

- 受体身份可检索 ⇒ 表征承载真实结构内容（非构造伪影）⇒ 管线重建有效。
- 与 Rashomon 观察的关系：稳定性门控与表征质量的互补。
- 局限：家族外泛化不等于结合预测；真实阴性仍缺；样本冗余（同一受体近重复）。
- 下一步：把身份表征作为预训练/初始化，接入有真实标签的结合任务。
