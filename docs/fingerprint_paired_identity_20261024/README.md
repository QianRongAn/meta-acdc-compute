# 完整配对变量链身份修复与开发诊断（2026-10-24）

身份证据以 [curation_v3/identity_registry.json](curation_v3/identity_registry.json) 为准。逐项保留完整沉积构建体、坐标可见序列、STCRDab编号变量区、边界和IMGT胚系核验依据。原始HTTP失败与重试均保留，未关闭TLS验证；Python对Oxford证书失败后，Windows原生curl通过正常证书验证读取。

准入要求：两个链角色由原沉积注释和STCRDab交叉核对；变量区必须为SEQRES唯一连续子串；STCRDab FASTA与编号表相同；变量区N端10位必须与对应功能性IMGT V等位基因相同、FR4末10位与功能性同类J参考相同。内部工程替换全部保留；末端变化或边界无法证实时隔离，不补残基、不按最近邻映射。该保守准入可能隔离真实的末端工程变体，不代表这些序列生物学上无效。SEQADV的“expression tag/linker”不能直接作为删除规则，其中可能包含真实CDR3；没有按这些标签批量删序列。

AF3须另核对CIF声明的完整聚合物序列、原图源文件哈希和明确alpha/beta角色FASTA，并精确包含一套已准入完整变量链。实际AF3构建体与沉积构建体分别保存；仅有文件名或坐标片段吻合不够。当前46张身份准入、285张隔离，准入35晶体+11预测；24个完整配对变量链序列ID。身份是实际沉积工程变量链的氨基酸身份，不是天然克隆身份、临床受体或结合真值。

v1为编号HTML末行空白填充未正确处理时的解析调试产物，v2为修正解析但未纳入成功重试来源的中间产物；二者不作为准入清单。v3为最终清单，全部历史文件保留。外部注释不是人工逐篇核查全部107篇原文的替代：这里核验的是结构工程序列及变量边界，不能据此声称临床构建体完全对应。

## 开发协议

[协议与源码/输入哈希](development/protocol.json)。保留旧fold0及原跨分区关联成分隔离，开发池25图/16身份，全部是此前消费过的晶体面板。原固定fit/validation按修正身份后，各旧家族只剩一个身份，困难负样本AUROC无定义；没有继续用坐标缺失造成的假负对。

新协议明确改成开发交叉验证，按相同物种、alpha/beta V基因组合分组，并保留旧家族和相同完整单链关联，不允许完整变量链或V基因组合跨训练/验证。仅有2个可定义困难查询的组，逐组留出，共8个困难查询；其余已准入开发图只作训练辅助。组选择仅依据身份、分组和正负对可定义性，不依据任何模型分数。它不是新独立验收，不能作为稳定外推能力的证据。

固定120epoch、3种子20261021/1101/4242；参考归一化、保留身份one-hot、后者的训练标签打乱对照，共18实例，另重放首实例。每个训练分区19/22图，均为一个批次，因此不再运行无法改变配对曝光的批次组织消融。只取最终epoch，不选种子、折或最好处理。基线为组成余弦、图大小（仅训练集标准化）和常数0.5；按查询、再按组等权。只有2个困难组，CI仅描述固定模型和画廊下条件波动，不作显著性或泛化证明。

独立SPR、功能、临床与保留验收集不读、不训练、不调参。全部原始数据、旧结果和隔离项保留。源码和协议先Git提交、再启动本轮训练；不得把开发诊断升级为结合预测或临床模型。
