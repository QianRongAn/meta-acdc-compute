# 构建体、剂量和归一化续核（2026-10-23）

本轮按既定标准继续补证，同时完善[E5/E6前瞻模拟协议](../e5_e6_protocol_20261023/README.md)。没有训练、选模或打开预留验收分数；没有重新划分旧测试或降低准入门槛。

## 必须更正上一轮的KRAS派生肽映射

上一轮保留了760个真实原始单元格，但从共享的氨基酸行标签直接推导所有位置的肽序列，未充分对照原始库。因此“744个唯一受体—肽对、20个原肽重复”的解释撤回。原始值、来源文件和历史派生JSON原样保留；它们此前没有用于训练、模型评分或独立验收。

本轮把`kras_peptides.xlsx`的Supplemental File 2逐条与完整肽序列核对。190条全序列均是所标位置的单点非原肽替换，但**62行的氨基酸注释列与全序列不一致**。不能仅靠该列作为真值。Figure 2C又对所有位置共用按V原位排列的氨基酸行标签；在原位不是V的5个位置，直接套用这些标签会得到20个不在库中的原肽项。按原始库的行顺序推导可得到另一套候选解释，其中244个读数的候选肽与直接读标签不同，但行顺序本身不是实际板位证明。

因此当前处理为：

| 来源单元格 | 数量 | 当前身份状态 |
|---|---:|---|
| 明确Cys位置ID，或原位V列的标签与全序列库一致 | 400 | 来源层面可核实肽对应；仍因构建体和归一化问题不进入训练 |
| 原位不是V的主矩阵列 | 360 | 保留原值、直接标签解释与原库顺序候选；正式`peptide`为空，身份未核实 |

修复位于共同生成入口`kras_cells/response`，不是只修改报告。`kras_raw_cell_ledger_v2.json`是本轮有效版本；`construct_condition_audit_v2.json`据此计算归一化对照。旧`construct_condition_audit.json`是本轮早期的初步版本，保留用于追溯，不能作为当前准入输入。确认400个对应不代表400个独立受体或可信结合标签，全部仍为候选。

## P-TEAM构建体：发现20条α链与Methods冲突

正文STAR Methods sec4.4.2写CMV构建体为β链含鼠mTRBC1、α链含**人hTRAC**。本轮从原始工作簿20个α链DNA单元格逐条翻译，再与UniProt官方参考P01848（人）和P01849（鼠）对照：20条α链的对应恒定区均与136 aa的鼠参考仅差一个T→C，位置47按该参考片段编号；它们不是人参考的精确序列。

这是文稿与附件的可复现冲突，**没有据此认定实际细胞一定用了哪一个构建体，也没有把序列改成人TRAC**。此前19对CMV DNA/蛋白初检通过，只说明附件内部一致，不代表实际实验构建体桥接已完成。20条全部增加构建体隔离原因，涉及全部3440条CMV读数；其中3268条此前通过序列初检仍不能放行。

7个RNF43受体保留独立变量/leader与constant DNA片段的翻译记录，没有拼造实际载体或临床cassette。R27的作者排除及序列问题不变。研究片段和专利链也没有升级成临床给药DNA。

## 剂量与归一化：能确认的和不能替代的

- **KRAS Figure 2C扫描：**10µM、16小时、HLA匹配K562与JASP90_CD8+ NFAT-EGFP，原文Methods可明确定位。760个原始值均有cognate、无肽APC、Jurkat背景及PMA/I对照。新账本同时保存按Methods和图注理解得到的两种归一化视图，含未截断和[0,100]截断值；它们明确标为本轮解释，不冒充作者实际实现。Methods的cognate/无肽与图注的PMA/unstimulated描述尚不一致，实际负对照的采用也需对应。没有根据模型效果选择视图。
- **P-TEAM：**已从出版社官方档案提取35页“正文＋补充材料”，Methods第17页和S14第27页另作视觉检查。24小时、细胞和MHC可以对应；所核材料没有明确写出两个人源面板各自的精确脉冲肽剂量。不能从被引的鼠源实验搬用默认值。
- **RNF43归一化：**原始NFAT乘`100/mean(PMA-I)`可复算；这是已核实的数值处理，不弥补缺剂量或构建体桥接。
- **CMV归一化：**原文说明按转基因表达细胞比例归一化；附件是处理后重复值，所核材料没有逐条原始分母，不能反推成独立原始流式测量。
