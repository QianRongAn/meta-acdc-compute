# 公开数据基准评测报告

> 汇总本项目在公开数据(VDJdb / IEDB / STCRDab / UniProt)上的全部基准,
> 并与文献对照。所有数字可从本仓库复现(命令见
> [`SOP.md`](SOP.md);逐条记录见 [`benchmarks.md`](benchmarks.md))。

## 0. 评测协议与指标

- **主指标**:AUROC(判别)/ AUPRC(类不平衡)/ Spearman(排名一致性)。
- **切分**:表位分组(epitope-split,防泄漏)与 PDB 分组(结构任务)。
- **类不平衡**:VDJdb 正负比约 1:13,故以 AUPRC 为主、AUROC 为辅。

## 1. 序列级基线(与文献对照)

任务:预测 TCR-肽结合(留出表位)。

| 方法 | AUROC | 说明 |
|---|---|---|
| 逻辑回归(理化 + 3-mer) | **0.609** | 本项目,epitope-split |
| ProtoNet(少样本) | **0.635** | 本项目 |
| MAML++ | 0.625 | 本项目 |
| 更大 ProtoNet | 0.621 | 本项目 |
| TITAN(文献) | ~0.62 | 跨数据集参照 |
| ERGO TPP-III(文献) | 0.669 | 跨数据集参照 |
| NetTCR-2.2(文献) | ~0.7x | 跨数据集参照 |

**结论**:序列方法一致聚在 **0.61–0.67**——**序列信息已接近穷尽**,任何
序列侧改进都无法突破。这为结构方法设定了"必须超越"的底线。

> 说明:文献数字为**跨数据集**引用(其官方环境 TF1.x/旧 torch 与本机
> Python 3.12 + torch 2.9 栈不兼容,无法同集运行);同集对照由内部基线
> 承担。

## 2. 结构诱饵任务(方法学核心)

任务:区分真实 TCR-pMHC 界面 vs 诱饵界面(PDB 分组切分)。

| 配置 | 位移诱饵 AUROC | 嫁接诱饵 AUROC |
|---|---|---|
| 序列基线(同任务) | — | 0.495(随机) |
| Cα-EGNN(v5–v8) | 0.946 | **0.500** |
| **v9.1(侧链接触,16 维边)** | **0.980** | **0.933** |

**Cα 不可分诊断**:嫁接诱饵在 Cα 图上 = 0.500,**且 3 倍数据(149→423)
不改善**——判别信息不在 Cα 表征中(表征层级问题,非数据量)。

**特征消融(嫁接任务)**:

| 配置 | AUROC |
|---|---|
| 完整 | 0.933 |
| − 侧链接触直方图 | **0.501**(决定性) |
| − 理化标量 | 0.606(大) |
| − 残基身份 | 0.899(中) |
| − 侧链伸展度 | 0.924(小) |

**结论**:侧链范德华接触是**唯一决定性变量**;这把"化学相容性"论点
钉死。

## 4. 主动学习模拟器(干-湿闭环数字孪生)

任务:从候选池用最少采样找阳性(以 VDJdb 作 oracle)。

| 采集函数 | 6% 采样召回 | 24% 采样召回 |
|---|---|---|
| 随机 | 5.9% | 24.3% |
| 熵 | 5.8% | 24.2% |
| MC 方差 | 9.3% | 28.8% |
| **EIG(BALD)** | **10.4%(2.0×)** | **33.0%** |

**阈值依赖边界**:增益是**预筛阈值的函数**——0.5 宽松池仍有 1.76×,
0.9 严格池消失(≈1.0×)。

**批大小消融**(预算 12%):大批 **3,600×2 = 24.5%** > 小批 300×20 =
21.6%(**反文献"小批多轮"**;弱模型下批量存在下界)。

## 5. MHC 呈递预筛

协议:50 个已知 HLA-A*02:01 结合肽 + 50 个组成打乱诱饵(难协议)。

| 阈值(top x% 诱饵分位) | 结合肽召回 | 压缩比 |
|---|---|---|
| 0.5% | 0.38 | ~200× |
| **2.0%** | **0.56** | **~50×** |
| 5.0% | 0.60 | ~20× |
| 10.0% | 0.72 | ~10× |

**结论**:top-2% 阈值即可压缩 ~50× 并保留过半真阳性——预筛假设成立。
(NetMHCpan 在线版因服务器不可达废弃,采用本地 MHCflurry。)

## 6. 跨实例稳定性(方法学判决门)

任务:同一批 AF3 候选结构,不同训练实例的打分排名是否一致。

| 阶段 | mean pairwise Spearman | 判决 |
|---|---|---|
| 未适应基线 | 0.17 / −0.24 / NaN | 不稳定 |
| 代理正样本(25) | 0.447 | 不稳定 |
| 63 天然 | NaN(种子塌缩) | 不稳定 |
| 89 天然 | 0.479 | 逼近 |
| **144 天然(21 候选)** | **0.729** | **稳定** |
| **144 天然(73 实例,过滤弱种子)** | **0.802**(CI 0.719–0.857) | **稳健稳定** |

**结论**:不稳定的根因是**训练数据规模**;扩样单调改善;过 0.5 门后
排名可报告。**任何外推打分结论必须先过此门**。

## 7. 临床金标准验证(KN-11)

A3A/MAGE-A3(5BRZ)案例,144-native 稳定 DA 模型:

| 肽 | 角色 | 分 | 家族内排名 | 致命 |
|---|---|---|---|---|
| EVDPIGHLY | 靶 | 0.984 | 1 | 是 |
| KVAKELVHFL | MAGE-A12 模拟 | 0.962 | 2 | 是 |
| ESDPIVAQY | titin | 0.924 | 3 | 是 |
| ILAKFLHWL | 脱靶 | 0.679 | 4 | 是 |

**结论**:两个**致死**脱靶与靶肽仅差 0.02/0.06——模型**不放过**致死
模拟肽(正确保守行为);第 3 个(0.679)**部分漏检**(诚实记录)。

## 8. 蛋白组尺度候选清单(KN-8,诚实负面)

人 Swiss-Prot 20,431 蛋白 → 465 万唯一肽 → MHCflurry 预筛 →
弱序列代理 EIG 排序 → top-50k。

- 靶肽 YLEPGPVTA 排 **3,149,734 / 4,654,973**(后 1/3)
- 已知 A2 阳性 **0/24** 进 top-50k(富集 0.0×,P=1.0)
- top 候选是 Q/E 低复杂度伪影(已加 `--max-aa-fraction` 过滤,阴性不变)

**结论**:弱序列代理的 EIG 不转移到蛋白组尺度——**真实订购清单必须等
结构模型重排**(管线、池、定位基础设施已就绪)。

## 9. 汇总:本项目 vs 文献

| 维度 | 文献/常见做法 | 本项目 |
