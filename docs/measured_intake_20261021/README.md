BATCAVE中同一PMID的4378行与上述原始记录一一对应，新增独立测量数为0。3440行CMV二手值对应原始归一化均值，938行RNF43二手值对应未归一化读数。CMV按TCR转基因表达比例归一化，RNF43按PMA/Ionomycin阳性对照归一化。不能把这些列拼成相同数值终点。
