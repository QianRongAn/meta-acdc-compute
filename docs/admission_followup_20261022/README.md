# 候选链、原始归一化及评估方案续核（2026-10-22至23）

本轮继续核查实测候选，同时评估用户提供的另一份AI分析。结论：新增了公开研究序列和逐单元格证据，但没有形成满足确认性比较条件的训练release，也没有生成新独立测试集或运行新模型。详细设计意见见[E1–E11与预登记模板复核](EVALUATION_TRAPS_REVIEW.md)。

## 新取得与核实的证据

1. **6对研究链候选。** 从US20220088190A1、US20260083847A1及WO2021074249A1/KR20220082046A同族公开序列表定位A3V、A11Va、A11Vb、A11Vc、A3-05、A3-10。原载序列、SEQ ID、配对条目、CDR及作用域存入`derived/sequence_evidence.json`。KR的SEQ9/256/261按三字母残基翻译并逐条核对声明长度；PDF109/110/179/183页另作视觉核对。没有根据V/J拼造缺失残基。

   KRAS四对来自完整研究链，含leader和constant；A3-05/10的原载“variable domain”也含leader。它们包含可变区，但本账本没有把未核实的成熟域边界悄悄裁成模型输入。配对CDR与原文Table1可对应，**尚不把专利研究构建体视作论文实际实验构建体逐字等价**。部分原文CDR终末F省略，保留约定差异。旧专利SEQ171是A3V不完整片段，SEQ26比完整β链少末位；本轮选用直接公开的完整链，未修改原条目。

2. **760个KRAS原始功能单元格。** Supporting Data Values的Figure 2C四个受体，各180格主矩阵和10格Cys补测。逐格保留受体、突变肽、来源坐标、原始NFAT-EGFP值、Jurkat背景和PMA/Ionomycin最大对照；共744个唯一受体—肽对。20格是原肽重复，不能把760都称为独立突变对。没有补造缺失的Val替换。

   16小时、10µM脉冲肽、HLA匹配K562、JASP90_CD8+ NFAT-EGFP流式来自该扫描方法。工作簿明确有PMA/I最大对照，符合图注；一般Methods描述的cognate肽最大值与此不同。账本额外保存明确标为“本轮派生”的未截断PMA百分比`100*(raw-min)/(max-min)`，**不冒充作者已发表cognate归一化终点，不作训练标签**。原始值和冲突仍完整保留。功能EC50没有转换为SPR KD。

3. **P-TEAM的出版社附件与Zenodo逐字相同。** 通过官方Europe PMC补充文件接口取得mmc4/mmc5，与已保存的RNF43/CMV工作簿SHA一致。因此TCR1-4的DNA/蛋白矛盾和R27问题不能归因于这两份附件的版本差异，原隔离继续。

   RNF43数值归一化可复算为原始NFAT乘PMA/I因子；CMV提供的是按转基因表达比例处理后的重复值，不能由它还原缺失原始分子。逐实验的精确肽剂量仍未从已核材料定位；不能从被引研究移植默认值。两种功能尺度及KRAS扫描不混为同一连续标签。

## 独立性更新：补齐序列可能减少可用测试量

沿用上一轮97个节点及保守来源边，对6个候选覆盖新取得的研究链，再重新计算序列排除边：暂定联合块由8变为**7**，序列排除分量由58变为**56**。`derived/identity_overlay.json`保留每条新边及输入哈希；旧图和旧冻结文件没有覆盖。

A3-05/A3-10共享公开的MAGE-A3野生型α链，新增序列均命中已有IMMREP保留身份，不能再按“缺链时未命中”认领新独立验收。**这不是证明它们与临床a3a的完整αβ工程受体相同。** 当前临床登记中的a3a CDR与该野生型α条目也不能直接画等号；临床工程构建体—给药—结局桥接仍未补齐。任一链的近缘命中用于保守排除，不用于证明同一结合谱或临床结局。

四个KRAS受体的这两套登记未命中，也不等于已经证明新独立家族。它们同属一项研究，且仍须完成构建体桥接和全部既有暴露范围核查，不能拆成四个独立来源做验收。
