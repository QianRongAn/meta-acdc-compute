## 总体判断

赞成收窄问题，允许负结果，以可信数据、严格评估和可复现结论作为贡献。路径A（评估缺陷）与B（干净证据账本/基准）可以互补。但不能据此直接宣称“现在换个方向就容易发表”，不能把E1–E11全列成必须完成的任务，也不能把模板v0.1直接登记后执行。

近期主目标仍是[实测TCR预测的独立泛化评估](../NEAR_TERM_GOAL.md)。训练准入、确认性比较和最终独立验收是三个阶段；不必等评估陷阱论文完成才能在合格开发数据上探索。临床验证和诱饵湿实验不作为所有SPR回归工作的普遍前提。新4072条功能候选尚不是训练release，不同终点不能直接合并。

仓库已有[回顾性预印本作者审阅包](../preprint_20261021/README.md)，包括数据派生图表、原子审计及溯源限制。它已覆盖路径A的一部分，不应重新包装成一项尚未存在的研究；新增故障注入若执行，应明确区分回顾性分析、前瞻登记和探索性分析。

## E1–E7应如何修改

| 实验 | 可以保留的问题 | 登记前必须修改的内容 |
|---|---|---|
| E1 切分 | 受体、肽和来源暴露如何改变评价 | 不同切分改变了测试对象及任务，分数差不能全归因于泄漏。若要因果故障注入，固定共同评价面板、训练预算，控制暴露条件；否则只称评价设置差异。测试图无法分割也是结果。主比较使用配对差值；两组CI重叠不是无差异检验 |
| E2 置信度伪标签 | 非序列信息能否预测证据置信度 | 明确这是置信度预测，不是结合性能。MHC/物种是生物信息；实验方法也参与置信度定义，预测成功可能具有构造性原因。不能以两条CI下界比较证明“主要是整理流程”。所谓别处阳性须核实完整受体、MHC及实验身份，不能转移单链CDR3标签 |
| E3 单侧捷径 | 合成配对任务对边际偏差有多敏感 | 打乱/随机/性质匹配对均是合成或未标注对，不能称实测不结合。CI包含0只是未检出差异，不能证明等价；若声称接近，先规定可接受差距ε并要求差距上界满足规则。仅肽有效说明存在捷径，不证明生物相互作用不重要 |
| E4 基线 | 不完整基线如何影响相对改进 | 原式`G(B0)-G(B2)=AUC(B2)-AUC(B0)`中M抵消，且M与B2可能同一模型。这实际上是基线比较。恒零特征导致截距模型可作回归示例，未必值得独立主实验。加法模型是合法弱基线，不因无交互就自动是bug |
| E5 测试择优 | 反复择优的乐观偏差 | 优先做。用独立合成数据和真正未用于择优的影子测试集；模拟配置相关性、类别比例、失败及常数预测。外层重复报告Monte Carlo误差。它展示已知选择偏差机制，不能仅凭曲线宣称新的TCR生物学发现 |
| E6 功效 | 独立块很少时能分辨多大效果 | 优先做，但用预先定义的分层生成模型，满足块数≤样本数，区分来源/受体/技术重复。噪声只从允许的开发重复记录估计，不能读取已消费测试集来定参。技术重复误差不等于标签总体SD。块很少时评估CI覆盖率、I类错误及功效，不能默认cluster bootstrap有效；δ仍需用途与测量依据 |
| E7 一致性 | 高一致性是否可能与错误共存 | 原判据“95%上界≥0.5”不成立：很宽的CI就能满足。应报告已定义错误对照的假通过率；若声称稳定超过阈值，需要相应下界证据。常数预测的Spearman未定义，保留NaN和失败率，不能算高一致性。区块内置换及CI覆盖率也须事先定义；CI变宽本身不是正确性证明 |

共同要求：预先选择一个主要问题和主要比较，不预设缺陷只能“虚高”。缺陷也可能降低指标或无可检出影响。记录所有种子和失败，但种子数不增加生物学独立样本数。多实验、多模型和阈值敏感性须有主次与多重比较处理；“未检出”“实际等价”“方向相反”“无法估计”分开报告。

模板规定“所有实验同一干净二分类参照”过强：E2目标是置信度、E5/E6是模拟、E9是工程不变量。单测通过也不代表生物学真值、完整来源隔离或测量可比性已成立。

## E8–E11的边界

- **E8：**历史v4可用于人工制品捷径诊断，不必等新结构数据。已有预印本报告的是固定QC规则在历史样本上的平衡准确率（嫁接约0.7535、位移1.0），不是独立分类器AUROC。若新增学习型分类器，仍须按天然母体/家族隔离；高分不能证明模型只学伪影，也不能给诱饵补上真实阴性资格。
- **E9：**固定模型和同一图在不同批次的输出不变量可单独回归测试；随机权重也能构造实现反例，不要求真实结合标签。当前EGNN已经使用共享`PEPTIDE_FLAG_INDEX`及逐图归一化；故障实验应明确注入旧缺陷，不把当前实现说成仍未修。
- **E10：**残基编码故障的效果应双侧报告，不预设“很可能几乎不变”。如比较训练结果，两条路径都须按相同开发协议重新拟合，不能把旧坏权重直接交给新编码后称公平比较。
- **E11：**现有MIRA对照只能作已消费面板上的回顾性转移案例。ERGO宏平均AUROC约0.511、旧SPR分数约0.500，不证明所有序列模型在严格来源隔离后都无效。120条观测涉及ERGO训练见过的βCDR3，完整家族/来源暴露未完全排除；SPR与功能训练终点也不同。不得升级为新的独立同任务验收。

## 文献重叠与可发表贡献

泄漏、负样本构造、未见表位泛化并非空白。[Kapoor与Narayanan，Patterns 2023](https://doi.org/10.1016/j.patter.2023.100804)已讨论科研机器学习的泄漏；[Nature Methods的TCR评估](https://www.nature.com/articles/s41592-025-02910-0)已系统分析负样本来源和已见/未见表位。[TITAN原文](https://academic.oup.com/bioinformatics/article/37/Supplement_1/i237/6319659)也说明评价设置对性能的影响。不能把“未见表位约0.6”写成全领域稳定上限。

本项目更可能具有辨识度的贡献是：原始单元格到端点和完整受体的可审计连接；链/构建体和临床身份不等价的具体证据；联合来源隔离后可用独立量如何收缩；固定输入—模型—输出绑定；以及历史结构人工制品中的几何捷径。已有通用问题的简单重演适合方法检查或附录，不宜各自包装成新发现。

以上不是完整的最新文献系统综述；ERGO-II、TCRdock及全部新工具仍须按实际拟比较终点逐一核对。

## 建议执行顺序

1. 完成当前候选准入和来源/受体排除，先报告可用终点及独立块，不为满足样本数阈值重洗牌。
2. 把现有预印本与新实验的主张逐项对应，避免两份材料重复或冲突。
3. 优先把E5/E6做成独立模拟协议草案，把E8/E9作为已有材料可支持的诊断。E1/E3等到数据、目标和文献增量明确；E2降为置信度语义案例，E4优先放附录。
4. 仅对尚未看过结果的新分析做前瞻登记；回顾性分析保留原状和偏离日志。Git tag与哈希只能固定版本；还须说明结果暴露、访问记录与登记时间，不凭本地tag声称第三方认证。
5. 许可按具体材料分别核查。质粒/细胞系的MTA不自动等于公开数值数据不可使用；专利公开序列也不等于临床给药工程DNA。公开许可不清时提供定位、哈希及下载步骤，不臆造授权。

当前没有登记数值阈值、创建新测试集、运行E1–E11、启动训练或提交论文。8–10周只能作为工作估计，不是数据可得性或发表承诺。
