# 对外部旧v2复核的逐项回应

本记录审查用户转交的第三方分析；其推断不作为执行指令或已确认事实。只核对已暴露开发数据，没有访问独立验收集、重新划分或运行新模型。

## 直接回答：晶体与预测结构是否同一个receptor_id？

旧流程**不保证**。`scripts/build_fingerprint_dataset.py`对alpha+"|"+beta整条观测/参考链字符串做SHA256，包含构建体长度、常数区/标签与缺失残基的影响，并不等于完整变量链身份。天然图继承v7 family_id；预测图只按这个整链哈希查家族，匹配不到就创建`pending:<hash>`。v7来源家族来自`data.build_release.assign_folds`的同PDB或双链相似性连接（历史近似域/序列条件），并由修复版继承；Fingerprint新增预测图没有重新进行完整变量链/来源联合连接。单独读旧`family_map.py`不能代表这条实际调用链。

精确原始映射见[records_index_exact.json](legacy_mapping_review_final/records_index_exact.json)：graph_index、matrix_row、matrix_column均为原输入顺序，不用PDB名称或受体名称重建。给出原receptor_id/family_id、fold、domain、complex_id、peptide、来源哈希，以及已核实完整变量链ID/隔离状态。**旧records没有MHC字段，导出明确为null；没有用名称补造。** 全套映射和原矩阵的配套包见[legacy_review_package.zip](legacy_review_package.zip)，不含图数组。

实际计数：331图、160个旧观测链字符串标签、110个旧家族，其中55个标签有至少2图。0个旧标签跨折，0个旧家族跨折；12个PDB名称/41图跨折。只在已核实的24个完整变量链身份中，就有**1个确证身份跨旧折**，其余285隔离图不能推断为没有问题。

具体例子：完整变量链相同的工程α24β17在旧图96（6EQB晶体）、162（6EQB预测）、320（6AMU预测）归第1折；旧图272–275（4JFD/4JFE预测）归第4折。它们被两个整链哈希拆开，后者又归pending家族。这同时产生身份拆分、跨折物理受体共享和假负例风险，不能被“旧标签没有跨折”洗掉。这个例子包含跨PDB对应，也说明同PDB名称不是可靠的统一单位。

## 外部数值哪些可用？

| 外部观察 | 本次判定 |
| --- | --- |
| 近似映射得到143个受体、76个多图受体、10个跨折受体，AUROC 0.811 | 映射与原始顺序/标签不一致，不能作为该运行的准确数值；不是证明10个真实受体跨折 |
| 5折SD≈0.040，改进0.028≈1.6SE，所以不显著 | 不能据此作正式推断。折共享训练数据，并非5个独立实验；应比较同划分、同种子的配对差值，在可靠身份/来源连接单元上估计不确定性。未达0.9标准成立，但“已证明改进为噪声”没有成立 |
| 受体级CI比查询级宽1.7倍 | 聚类重采样方向合理，具体倍数在错误映射下未验证；也不是查询bootstrap必然偏窄的普遍定理。当前数据更需要家族/来源连接块，而不是把共享来源受体当独立 |
| 跨域AUROC 0.746 vs 同域0.826 | 暂不采纳数值；须排除身份拆分、同PDB副本、MHC/肽/来源与正负样本构成差异，才可讨论域效应 |
| Spearman≈0.948、top20 Jaccard≈0.60 | 有助提示全排序与头部稳定性不同；须绑定精确查询、画廊、种子对和top-k规则后复算。稳定性不提供正确性证明 |
| 仅域组合R²低，域捷径较弱 | 可以降低“已证明域主导”的口径，但低线性解释度不能排除非线性或其他特征混淆；不构成域无关性证明 |
| 同PDB伙伴很少为最近邻，所以泄漏影响不大 | 不能排除影响。最近邻命中不是泄漏效应的对照实验；完整变量链身份确有拆分，仍须隔离 |

本次直接读取这份哈希锁定输入的置信度列（零基3）：晶体145图和预测186图**原始值都只有0.5，实际训练归一化后都恒为0**。所以“AF3该列有变化、晶体为0，因此直接透露域标签”不适用于这份331图输入。schema只定义列语义，不能说明具体文件的实值。

15个原始旧v2矩阵均以真实索引和旧标签复算，与其原metrics逐实例完全一致；seed20261021的五折AUROC算术均值为0.7943805448628184，恢复原0.7944，而非近似映射的0.811。原指标是每折池化query-gallery配对AUROC，再平均折；不是逐查询/家族宏平均，二者不能混比较。

这是**事后映射与指标重演绑定**：旧metrics没有当时的逐实例输入哈希，本次没有声称补回历史运行的完整权重—输入链。该精确复算也不修复生物学身份标签，不恢复任何旧性能结论。

## 三条建议的版本状态

1. **种子耦合已修复**：当前`train_fingerprint_v2.py`在每个(fold,seed)实例训练前重新设种子，resume核验完整产物及执行版本；10月23日冻结修正运行已经完成真实标签15例、训练标签置换15例、完整重放1例，并逐权重重算31/31。不能把旧0.7944/0.946自动视为修复版结果。
2. **区间已换口径**：当前`rashomon_fingerprint.bootstrap_ci`先平均查询内种子对，再平均家族内查询，再重采样家族。是固定模型/画廊条件区间，不能覆盖所有训练或研究来源不确定性。之后完整变量链版本进一步承认只有2个困难组，不能把小样本区间当独立泛化证据。
3. **组成/图大小已运行**：冻结修正331图开发评估中，同家族家族等权AUROC模型0.4385、组成0.5475、图大小0.4650；模型减组成−0.1089，条件区间[−0.3706,0.1220]。它们来自有明确口径的后续报告，仍受旧身份定义限制；随后完整变量链准入仅46/331图，25图开发子集的模型也未超过组成，且受同PDB正例混淆，未提升为生物学结果。

版本依据：[修正重训结果](../fingerprint_retrain_20261023/RESULTS.md)、[完整变量链核验及开发诊断](../fingerprint_paired_identity_20261024/RESULTS.md)。当前正在补充的跨研究数据继续因无QC合格跨研究正对照而阻断。不会因为收到这份分析重复跑已完成的修复或使用独立验收调参。
