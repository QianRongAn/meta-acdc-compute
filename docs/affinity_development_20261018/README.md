# 亲和力基线：训练／验证诊断与限定改进（2026-10-18）

结论：近常数预测反映当前辨别能力不足；这轮没有得到优于原基线的新模型。未使用已经消费的测试集调参，也没有给新预留数据打分。保留阴性结果，不按预测范围更大挑模型。

## 诊断证据

原开发集只有10条训练观测、5个独立训练块，却有1014个输入特征。加权中心化后的训练矩阵秩最多9；多数方向约束很弱。原模型中，MHC6维的训练加权方差总和0.819，仪器3维0.560，而1005维序列／交互特征总和仅0.343。未统一量纲的Ridge惩罚与这些尺度相互作用，容易压缩弱序列方向。

原验证10条中，MHC贡献的预测标准差0.271，仪器0.051，序列0.057。验证出现训练未见过的MHC、仪器和序列词，DictVectorizer会忽略未知键；这可能使跨来源预测退向截距。贡献有相关性，不能相加或视为因果重要性。`diagnostic_initial.json`来自训练／验证重建，未读取旧测试输出；`diagnostic_followup.json`只用固定模型和源隔离后的9条验证计算贡献。

另有明确表示局限：ACADACA与ACACADA具有完全相同的旧1-mer/2-mer和组成交互特征，却是不同序列。新区域特征能区分这个最小例子，但这不证明其生物学有效性。

以上是可复现的机制和小样本限制，不是已证明唯一的成因；不能把常数输出解释为经过校准的“不确定性”，也不能强行扩大输出范围当修复。

## 新外部实测数据与限制

新建[独立预留池](../fresh_spr_reserve_20261018/README.md)：IY11受体TRAV24/TRBV27，HLA-C*12:02，两条实测SPR。WT为主分析候选，9A因超过明确展示的动力学浓度范围保守列入敏感性分析。它们属于同一个受体、同一研究来源，不能计成两个独立受体。

该来源已在新候选拟合前从开发集中隔离，但参考模型alpha1继承了此前包含3B的验证选择。删除3B不能消除这段配置选择历史，因此不能把保留下来的参考模型称为在IY11上实现严格来源独立验收。三个新候选没有超过参考模型，本轮不启动独立验收。

新池只有1个来源/1个连接块，原门槛要求至少3个来源/3个连接块，仍未满足；保留未打分、不可训练状态。新发现的IW9四条测量虽有数值、仪器和25°C，但公开原文/补充材料未能把完整配对可变区与四个SPR受体编号对应，隔离而不补造。其余候选缺口逐条列在预留池中。
