# 修正后的Fingerprint重训与评估协议（训练前冻结）

机器协议见 [protocol.json](protocol.json)，字节锁见 [protocol.sha256](protocol.sha256)。这是已暴露开发面板上的前置冻结执行协议，不是新的盲测预注册；旧0.7944和组成基线结果在冻结前已知。原始折分配复制并绑定，不重洗牌。

固定历史v2配方：6层128维不变EGNN、128维嵌入、batch64、120epoch、温度0.07、同家族负样本权重1、3个种子×5折；只修边偏移与实例种子等已确认错误。CPU双线程、严格确定性；不调参、不早停、不挑种子，最终epoch只评估一次。再完整重放首个实例核验确定性。

组成余弦、图大小余弦（恒定诊断）、对数节点数距离及半径距离作为基线。同家族困难负样本是主口径，全部同受体阳性保留；同家族不同受体为负。当前仅62个查询/11家族有双类，其他记无定义，不填0.5。主效应是每查询模型减组成AUROC、先平均种子再平均家族，并按家族bootstrap；正向开发证据规则在机器协议中固定。没有合理应用阈值，不宣称实际或生物学意义。

对照只打乱训练图上的(受体,家族)联合监督标签，保持标签频数和类-家族关系；初始权重/训练打乱种子与真实标签组配对。评估用真实标签；测试图完全不参与置换。每折3次置换只作描述性对照，不给置换p值。所有种子保留，包括坍缩或表现不佳者。报告全体及同家族排序稳定性，不能将稳定性当准确性。
