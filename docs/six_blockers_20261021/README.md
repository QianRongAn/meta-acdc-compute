## TCR4：补上物理非检出证据，没有新增独立谱系

[Ma等2025原文](https://doi.org/10.1038/s41467-025-56004-8) Figure 1c/d、Methods及原始Source Data共同支持：Biacore T200，4°C，TCR固定、pMHC作分析物，1:1稳态拟合；Neo的KD为62±6 µM，WT最高实测分析物浓度208.24 µM下未检测到结合。s3-4对WT样品仍有结合，提供样品有效性对照。

没有把208.24 µM直接写成KD下界，因为还缺可量化LOD/Rmax假设。WT的KD、普遍结合标签及临床标签均空。未把HLA-A2的无关gp100控制混入同MHC训练数据。细胞功能图1b的XLSX列名与论文坐标单位不一致，也未据此转换细胞剂量指标。

`7L1D`官方αβ链序列和原文身份可对应，但 `tcr4_exposure_audit.json` 确认它与2022年已有TCR4谱系相同、已进入消费过的验收集，并与开发文献共享作者Baker BM。新增测量只作证据扩展，**新增独立受体/验收记录计数均为0**，没有打分或转入训练。

另一个来源35589842也把某受体叫TCR4，CDR3却不同；候选索引用PMID、构建体及序列定义身份，不按同名合并。

## 真实研究数据：原始附件、翻译与隔离

[BATCAVE作者数据库](https://github.com/meyer-lab-cshl/BATMAN-paper/tree/37d8d1ba23921d90736418b7b6cd62a5cdf68a91)两张功能表共22827行。人源记录12731行，其中5798行通过本轮完整规范αβ序列及CDR3包含检查；这是序列完整性筛查，尚未逐篇完成所有实验条件验收。功能零反应不转换为物理不结合。

独立的KD汇总表560行中67行带大于号，核对受体后全部是鼠源；425行人源记录没有这种非检出界限。它们不能充当67条人源真阴性，也不把二手/数字化数值直接当原始精确SPR表值。

进一步从[P-TEAM原始研究](https://doi.org/10.1016/j.xgen.2024.100634)作者Zenodo附件取得27对人源研究受体DNA和反应矩阵：

- 20对CMV受体中19对通过DNA翻译、原载蛋白和CDR3检查；TCR1-4的β链DNA翻译与附件蛋白不一致，隔离，未选一版覆盖另一版。
- 7对neo-epitope受体中6对通过规范框架和CDR3检查；R27的α链余1个碱基且原作者已排除，保留原文排除状态。此表把变量/leader与constant分列，未拼接成自称“完整临床工程DNA”的新链。
- 25对通过上述检查的研究受体对应4072条功能反应测量，供继续核查；未阈值化成分子结合标签，未训练或评分，也未按受体数量冒充独立家族数。

以上P-TEAM观测与BATCAVE二手汇总有重叠，不能相加凑样本。新数据尚未完成全部家族/研究来源独立性与训练协议核验，没有重新洗牌冻结验收集。原始DNA、未通过行、研究用constant片段及作者排除记录均保留。
