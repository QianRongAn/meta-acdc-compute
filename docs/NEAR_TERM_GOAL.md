# 近期研究目标（2026-10-21）

> 在终点明确、受体和来源严格隔离的实测数据上，现有方法能否比简单基线提供稳定、具有实际意义的预测增益？

本目标取代近期以结构分数、模型规模或临床风险演示为主要交付的方向。研究允许得出“未发现增益”或“证据不足”；不预设复杂方法必须获胜。历史撤回、数据隔离和模型放行限制继续有效。

## 数据与任务

先按同一终点建立可追溯的比较：SPR亲和力回归、细胞功能预测分别立项，不混合标签或跨任务比较数字。亲和力记录保留单位、温度、测量格式、构建体、原文定位及删失状态；非检出按实验条件保留，不能强赋精确KD或普遍不结合。功能零反应不能替代分子不结合，合成诱饵不能替代实测阴性。存在序列矛盾、协议不明或来源无法追溯的记录先隔离。

在任何模型开发前，按完整αβ受体身份、近缘受体家族及研究来源建立联合排除关系；同一受体的突变体、不同命名、重复数据库记录和论文/预印本/附件版本不能跨分区。同家族或同来源相连的记录按连接块分配，测试块与训练、验证同时隔离。家族定义、V基因信息和来源归属必须有可审查依据；信息不足不能宣称独立。报告各分区受体、家族、研究来源与连接块数量。

当前已消费的冻结测试集和MIRA面板只保留为历史分析。后续验收使用新的、未参与模型选择的独立实测来源；不重新洗牌旧面板凑验收量。新候选完成身份、来源及协议核查后，才建立带哈希、版本和访问记录的冻结集。独立块不足时明确报告验收能力不足。

## 公平比较

亲和力任务至少保留训练集均值预测和正则化线性/岭回归；功能任务至少保留训练集阳性率与正则化逻辑回归。输入特征必须符合相应任务；受体、肽、MHC和实验条件的可用信息在比较中明确对齐。加入仅肽、仅受体等简单对照，检查增益是否仅来自边际偏差。外部工具仅在相同终点、相同观测且训练暴露可审查时纳入主要比较。

现有方法与简单基线使用相同开发切分、合法输入和预先规定的调参预算；只在训练/验证数据上拟合、选择特征和超参数。事先固定种子、重复运行数、失败判据及处理方式，保留全部运行及失败比例，不挑选表现好或排名一致的种子。

## 锁定与验收

在访问新测试标签或分数之前登记：任务与适用范围、主要指标、简单基线选择规则、实际最小增益阈值δ、独立块数量/精度要求、置信区间方法和失败规则。δ须依据测量重复误差与预期用途确定，不能看完测试结果后调整；目前尚未确定数值，不构成可执行的性能放行协议。

亲和力可预先指定pKD的MAE或RMSE为唯一主要指标，另一项作辅助；功能预测须按终点和患病/反应比例预先选择适当指标。比较模型对基线的配对误差差值，按联合隔离的独立块估计不确定性，逐来源报告表现，并记录种子变化、缺失和失败。相关性或跨种子一致性不能代替准确性。

先锁定代码、数据处理、模型权重及验收协议，再进行一次独立验收。只有主要增益方向正确、达到预登记δ、其不确定性满足事先规则，且跨来源与重复运行未触发失败标准，才可声称在该终点和适用范围内获得稳定、具有实际意义的增益。验收后测试集标为已消费；若回流开发，必须另找独立验收数据。一次阳性结果不外推为临床安全性或广泛结合预测有效。
