# E5/E6前瞻模拟协议 v1.0

2026-10-23。任务是完善评估设计，不使用新旧生物验收结果校准模拟。`E5_plan.json`与`E6_plan.json`是机器可读的权威计划；本页解释其科学含义。Git提交及专用tag固定本版本，不声称已在OSF等第三方平台注册。

## 暴露边界与执行状态

- 研究数据全部合成。既有SPR、MIRA、临床、结构分数、新候选响应及预留验收标签均不作为模拟输入。
- 尚未执行5000次主研究或敏感性运行。协议校验只检查参数、自洽性和解析性不变量，不据此报告经验功效或性能。
- 固定版本后，首次统计运行还须绑定实现源码、依赖版本和执行命令的哈希。实现必须遵守本协议；任何设计变更先提交偏离记录，不以试运行结果调格点、阈值或重复次数。
- 所有结果允许为零效应、方向相反、证据不足或无法估计。不得挑种子、删失败记录或仅展示显著单元。

## E5：在测试集择优会产生多少乐观偏差？

每个独立重复生成平衡二分类标签，以及与标签独立的50列正态候选分数。候选之间相关系数ρ为0、0.5、0.9、1；这模拟配置共享偏差，而不是假设50个模型相互独立。没有训练步骤。

在n=14、50、200的“被滥用测试面板”上，分别从前k=1、2、5、10、20、50个候选中选最大AUROC；相同时取最小索引。所有k共享同一面板和50列分数前缀。然后只对选中的候选，在**独立生成的200条平衡影子面板**上评价；影子结果不参与选择。

唯一主要估计量：n=14、k=20、ρ=0.5时，`选择面板AUROC−影子面板AUROC`的5000次重复均值。另报告相对k=1的配对增量、未校正择优后的单侧p≤0.05比例、候选选择索引和全部失败。该指标描述已知零信号条件下的选择乐观偏差，不是新生物学预测性能。

AUROC用平均秩处理并列。n=14、无并列时，朴素p值使用单侧精确Mann–Whitney；其他非恒定条件使用明确固定的渐近算法和连续性校正。它是故意未做择优校正的诊断量，不是正式多模型显著性结论。恒定控制保留AUROC=0.5、p=1；ρ=1控制的候选完全相同，不应随着k增加而改善。

均值的区间是5000个独立外层数据集产生的Monte Carlo区间；单次结果分布的2.5/97.5分位数另行标注，不混为均值置信区间。概率报告Wilson区间。所有网格是预先指定的敏感性分析，不另选“最有冲击力”的主结果。

## E6：独立块极少时，区间和功效是否可信？

研究对象是成对预测误差的分层合成分布。来源块相互独立，块内嵌套最多两个受体家族，家族内有多行。n和b不取任意无效笛卡尔积；固定13个情景，主要情景为n=14、b=3，来源预测误差方差比例0.5、技术误差SD=0.3、两模型潜在误差相关0.9。其他情景覆盖b=2/5/8、n=50/200以及预先规定的一次只改一个参数的敏感性。

**这些数值是压力测试假设，不是从已消费测试集估计的领域参数。** 技术误差与来源误差、受体误差分开。基线总体RMSE固定为1 pKD，候选总体RMSE由明确缩放公式设为`1−Δ`，Δ取0、0.01、0.03、0.05、0.10、0.20。两模型对同一条测量共享同一技术噪声，因此总体改进Δ可解析核对。它不是一个使用真实标签的训练实验。

每个单元5000个独立合成数据集，每个数据集1999次重采样，比较三种方法：

1. **来源块bootstrap**：整块抽样，保留所有嵌套家族、行及成对误差；重算合并RMSE差。双侧95%分位区间评估覆盖率，单侧95%下界>0判改善。
2. **逐行bootstrap**：相同抽样次数，故意忽略相关结构，仅作为错误指定的比较方法，不作为推荐验收法。
3. **整来源模型标签交换**：枚举全部2^b种交换，只在所设零效应生成模型的交换性成立时解释其检验性质。不能直接声称对现实数据同样“精确”。

唯一主要估计量是主要情景零效应下来源bootstrap的双侧95%覆盖率；单侧假通过率是必须同时报告的关键次要量，不能取代主指标。改善规则的名义单侧α=0.05；双侧95%覆盖率是另一个量，二者不能混算。其他效应下报告功效、区间宽度、失效率和Monte Carlo精度。

一个可以事先证明的限制：整块枚举交换检验的最小单侧p是`1/2^b`，所以b=2或3无法达到0.05。这个离散性结论不需要打开任何生物测试结果。

网格MDE定义为：功效的Wilson下界达到0.80的最小正Δ；方法同时必须通过预先规定的零效应假通过率检查，bootstrap还须通过覆盖率检查。0.07/0.93是对名义0.05/0.95的2个百分点方法学容差，不是生物学放行标准。表观功效高但覆盖率不合格时，必须标记不合格，不能据此“放行小样本”。未达到时报告`>0.20`或不可估，不看结果追加更有利的格点。

## 不能由本协议决定的事

真实数据的实际最低增益δ仍须由允许使用的开发重复误差和具体用途建立证据。当前没有足够依据给数，`application_gate.actual_minimum_benefit_delta`保持空值，实际数据放行映射被阻断。这不影响完成已明确指定的合成研究，但不能拿模拟SD=0.3直接充当实测技术误差。

本协议不决定受体至少15/20个即可用，也不把旧n=14的微小点差判成“已证明是噪声”。受体数量、来源块、误差结构及目标效应必须一起看。

## 复现与变更控制

随机数固定NumPy PCG64，种子由实验版本、情景、外层重复及流名称的SHA256确定。E5的键不含k；E6的键不含Δ，使候选前缀和效应格点使用预先规定的公共随机数。标签、候选分数、影子分数及重采样使用独立流。不得因结果不显著增加重复次数。

`scripts/validate_e5_e6_protocol.py`只验证计划、情景合法性、误差总体恒等式及枚举分辨率，不运行主实验。当前数据准入缺口见[构建体及协议补证](../protocol_followup_20261023/README.md)。未新增或重分配验收集。

偏离日志：本版本发布前只有数学和参数校验，尚无主研究结果；发布后的变更须新增版本，逐项记录时间、原条款、新条款、原因及是否已见对应结果。不得回写旧计划。
