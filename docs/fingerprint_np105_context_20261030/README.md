## 2. β J的ORF标记已查明原因，但不能改成F

[IMGT官方TRBJ基因表](https://www.imgt.org/IMGTrepertoire/LocusGenes/genetable/autotable.php?group=TRBJ&species=Mus+musculus)将TRBJ1-6*01列为ORF，注释4说明其J区为Phe-Ala-X-Gly，而非典型Phe-Gly-X-Gly。NP105原观察编号118–121为**FAAG**，与这一原因相容。[官方等位比对](https://www.imgt.org/IMGTrepertoire/Proteins/alleles/index.php?gene=TRBJ1-6&group=TRBJ&species=Mus+musculus)也列出对应53nt序列。

[可复核事实与原始页面哈希](J_ORF_reason.json)。这里的ORF是胚系参考的功能注释；不能据此说重排后的NP105没有表达或必然不具功能。反过来，观察到表达和原文功能实验也不允许把数据库ORF改写为F。固定F/(F)准入门保持原样。

已补充官方注释依据；**基因组相位、唯一V/D/J切除/N插入边界仍未解决**。原αV核苷酸参考匹配与蛋白多解、原HMM J首位标签等均见[前轮取证](../fingerprint_np105_raw_20261029/README.md)，没有更换参考快照或按结果重定门槛。
