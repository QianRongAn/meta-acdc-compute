## 1. 研究背景与问题

TCR-T 疗法的安全危机有据可查:MAGE-A3 亲和力增强 TCR 的两项临床试验
分别因 titin 与 MAGE-A12 交叉反应致死 4 名患者(Cameron 2013, Linette
2013, Morgan 2013)。晶体学证据(Raman 2016)表明致死机制是**直接分子
模拟**——titin 肽与 MAGE-A3 肽骨架 RMSD 仅 0.285Å,CDR 环构象一致。
此类交叉反应无法用序列比对预测(序列相似性低),是序列模型的结构性
盲区。

**前期实证(本工作)量化了两个瓶颈**:
1. **序列天花板**:逻辑回归/ProtoNet/MAML++ 在留出表位设定下全部聚于
   AUROC 0.62-0.64,与文献(TITAN 0.62, ERGO TPP-III 0.669)一致——
   序列信息已穷尽。
2. **结构表征层级**:Cα 级图(文献最常见分辨率)对"化学改变、几何不变"
   的界面信息论不可分(AUROC 0.50,3 倍数据不改善);加入侧链范德华
   接触特征后升至 0.933(消融确认)。

**核心科学问题**:能否用几何深度学习,在蛋白组尺度预测 TCR 的交叉反应
风险,把"不可预见的致死脱靶"变成"可排序、可验证、可解释的风险清单"?

## 2. 研究目标(干实验范围)

1. **Meta-TCR-GNN(方法学)**:EGNN + 侧链接触特征的界面图模型,学习
   TCR-pMHC 化学相容性;元学习支撑少样本泛化。
2. **主动学习干-湿闭环的模拟验证**:EIG 采集 + ε-greedy 的模拟闭环,
   量化"智能采样 vs 蛮力筛选"的效率增益;作为未来 ACDC 湿实验闭环的
   数字孪生。
3. **蛋白组尺度安全评估系统**:AF3/TCRmodel2 结构预测 + EGNN 打分 +
   每 TCR 排名 + 交互式风险看板(TCR-Safety-Radar)。

## 3. 方法(已实现管线)

### 3.1 数据
- VDJdb(199,289 条,178,974 独特 CDR3-β,2,068 表位)——激活标签
- IEDB mhc_ligand_full(2,302,095 条)——递呈级数据
- 291 个 TCR-pMHC 共晶结构(STCRDab 自动分类;内容型链角色分类解决
  PDB 链字母不一致问题;多复合物拆分 ×2.8 数据增强)

### 3.2 模型
- 界面图:10Å 界面 / 8Å 边;节点 = 理化性质 + pLDDT + 残基身份 + 肽标志
  + 侧链伸展度;边 = RBF 距离 + 侧链 vdW 接触直方图(4.5Å,类型分箱)
- EGNN(E(3) 等变,不变性验证 <0.002)
- 元学习:ProtoNet / MAML++(逐参数可学习内环学习率)

### 3.3 诱饵构造协议(可复现性核心)
- 位移诱饵:肽链平移 6Å(几何破坏)
- 嫁接诱饵(结构模拟):Kabsch 骨干对齐移植外来侧链——骨架/节点集/
  肽标志不变,仅侧链化学改变
- 防泄漏:节点集 pin、供体序列去重、PDB 分组切分

### 3.4 评估管线
- AF3 网页版结构预测(条款合规,手动提交)→ mmCIF 解析 → 界面图 →
  EGNN 打分 → 每 TCR 排名(rank_eval:recall@0.5 + 天然肽排名判决)

## 4. 初步结果(截至 2026-09-22 晚,全部记录于 docs/benchmarks.md)

| 实验 | 结果 |
|---|---|
| 序列天花板 | AUROC 0.62-0.64(ProtoNet/MAML++,留出表位) |
| Cα 不可分诊断 | 嫁接 0.500,3× 数据不改善 |
| **侧链接触突破** | 嫁接 0.933 / 位移 0.980;消融确认接触特征为唯一关键变量 |
| 特征消融 | 接触(决定性)> 理化标量(大)> 残基身份(中)> 侧链伸展(小) |
| 主动学习模拟 | EIG 在 6% 采样 2.0× 阳性召回增益;EIG > 方差 > 熵 ≈ 随机 |
| AF3 排名(首批) | A6 TCR:5/8 VDJdb 验证肽 0.96-0.99;B7×Tax 0.999 |
| 种子方差 | 嫁接 0.920/0.741/0.692——小数据高方差,需多种子报告 |
| **结构↔特异性资源**(新) | 281/291 复合物映射 VDJdb;2,309 CDR3 命中(1,517 异表位) |
| **MHC 预筛基准**(新) | MHCflurry 本地:top-2% 阈值 0.56 召回 / ~50× 压缩(难协议) |
| **跨实例不稳定危机**(新) | AF3 排名跨实例 Spearman 0.61/0.11/0.33/3×NaN——不可复现;独立复核确认;域适应修复进行中 |

**关键阴性结果及其意义**(已写入 README 实验日志):
- 单对绝对打分未检出 MAG-IC3/titin 模拟(0.605 vs 0.223)→ 定义排名式
  问题设定
- 序列+图混合无增益(0.905 < 0.933)→ 结构接触特征自足
- 熵采样无效(≈随机)→ 支持 EIG 选择
- **Rashomon 效应**(2026-09-22):诱饵任务=插值(可复现),AF3 排名=
  外推(跨实例不一致)→ 论文 1 以稳健的诱饵任务+表征发现为核心;
  排名能力需更大数据规模 / 域适应(TCRmodel2 批量 111 复合物已提交,
  流水线自动运行)
- MHC 预筛在 VDJdb 池上不提升阳性密度(7.0%→6.9%):VDJdb 阴性本身
  多为可呈递肽——密度增益需真实免疫肽组库,记录为模拟器局限

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 结构预测质量(AF3 对 TCR-pMHC DockQ ~0.5) | 多模型集成 + ipTM 过滤 + TCRmodel2 交叉验证 |
| 小数据训练方差(种子 0.69-0.92) | 多种子报告 + 数据增强(拆分/AF3 批量) |
| AF3 条款限制(自动化结合预测系统) | 网页手动提交 + TCRmodel2 条款安全替代 |
| VDJdb 标签噪声(score=1 弱阳性) | 天然肽对照 + 金标准案例仲裁 |
| **跨实例排名不稳定(Rashomon)** | 域适应(TCRmodel2 结构混训)+ 稳定性判决门
  (da_stability.py,mean Spearman ≥0.5 方可报告排名) |
| TCRmodel2 服务排队不可控 | 批量已提交 + 轮询自动化;预计 48h 内回收 |
