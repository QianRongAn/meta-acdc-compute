## K82N候选：保留失败证据，禁止自动修正

条码TCGGGACTCGTGGGAA的α组装在IMGT82出现K→N，变量区第201个核苷酸A→C，密码子AAA→AAC。该细胞只有两条覆盖该密码子的输入读段：

- 一条AAC，变体C的质量为**Q12**（三位质量37／32／12）。
- 一条AAA，通过三位均Q≥30的检查。

在当前白名单有界reads中，Q≥30、MAPQ≥30的完整AAC密码子支持为0；100个条码＋UMI组合在**同一条读段**上同时支持AAA与精确、全长且逐位Q≥30的目标α CDR3。组装候选不据此自动改为AAA，也不作为新天然受体、模型正例或新身份。它被隔离为未获高质量原始读段支持的组装候选；**尚未证明它必然是某一种测序或PCR错误**。

附带观察也全部保留：局部候选比对中还有AAG等密码子，其中AAG为同义K；它们没有通过同一读段精确CDR3连锁条件。不能把这些局部比对直接解释为NP105的已验证变异，也不能据本前缀断言全run没有异质性。逐读段质量、UMI、位点与连锁统计见`variant_raw_support.json`。
