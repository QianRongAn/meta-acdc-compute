## E7/E14：重算统计口径，不恢复旧结果

[最终Rashomon分析](corrected_rashomon_v3/rashomon.md) / [JSON](corrected_rashomon_v3/rashomon_results.json)。家族等权排名rho0.9477，条件95%CI [0.9423,0.9530]，331查询/110家族。只是在原缓存上改变了估计和抽样单位，不能宣称统计修复后模型已获验证。家族不代表来源独立，区间不覆盖共享训练集、固定画廊、模型重训或种子总体的不确定性。

固定组成分数复制成多“实例”，只要查询排序非恒定，rho便为1；这是确定性反例，不是打乱标签训练实验。单独一个正节点数的余弦全为1，AUROC0.5；若算Spearman则无定义，不能填0或1。

Procrustes现在只使用每折训练图拟合旋转、对测试查询评估。它保留各实例内部余弦，不能增加检索能力。缓存float32相似度与float64重算内积在近并列处存在微小AUROC差异，JSON记录该精度差异和旋转误差，不解释为提升。rank1_agreement明确是命中状态一致，包含两者都错，并非找到了同一个邻居。
