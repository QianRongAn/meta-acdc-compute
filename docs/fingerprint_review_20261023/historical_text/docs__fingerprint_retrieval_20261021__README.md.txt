## 解释范围（重要）

- 阳性发现：**审计修复后的管线训练出的结构表征，能在家族外（未见受体）条件下，
  以 13× 机会水平的 rank-1 检索出同一受体的其他结构**（226 个查询、5 折一致）。
  这说明表征承载真实结构内容（受体身份），而不是构造伪影或域签名。
- 这不是结合预测：受体身份 ≠ 结合标签。它只证明"结构 → 受体身份"这条信息通道
  已在修复后的管线中打通——下游任何结合/脱靶应用的必要前提。
- AUROC 0.767 说明同一家族内的不同受体在表征中仍有混淆——正是后续工作的靶点。

## 后续：AUROC 差距诊断 + 收紧 + Rashomon（2026-10-21）

训练后诊断（`auroc_gap_diagnosis.json`，只读已有产物）发现：

- 全体图两两余弦相似度全部落在 **[0.9957, 1.0000]** ——表征近乎坍缩；
- 同家族对 AUROC ≈ 0.52（机会水平）；跨家族对全为负样本（受体→家族一致）；
- 同一权重重新嵌入，折 AUROC 波动 ±0.01–0.02：0.767 建立在 4e-3 相似度带宽内的
  微弱排序差上，指标本身对浮点噪声敏感。

据此预注册了跟进实验
[FOLLOWUP_AUROC_RASHOMON_20261021.md](FOLLOWUP_AUROC_RASHOMON_20261021.md)：
v2 配方（batch 64、去投影头 LayerNorm、温度 0.07、嵌入 128 维、120 epoch 余弦
退火、同家族难负样本加权 λ=1.0）收紧 AUROC 差距，并对新表征做 Rashomon
（跨实例稳定性）分析——按 SOP 要求，任何 OOD 打分结论必须过跨实例稳定性检验。

**结果（15/15 实例完成，按预注册标准原样判定）**：

- 池化 AUROC **0.7666 → 0.7944**（+0.028；展开的 fold 1 达 0.8116）——方向正确，
  但 ❌ 未达 0.9 门槛；表征仅部分展开（两两余弦中位数 0.9998 → 0.9869，❌ 未达
  ≤0.95 门槛）；rank-1 13.5× 与域诊断 0.42 ✅。
- Rashomon：**排名稳定性 ρ = 0.946**（已撤回旧管线的同型指标为 0.644）；rank-1
  一致率 0.958；判决翻转率 0.092；Procrustes 对齐后同图一致率 0.993——跨实例
  几何稳定。
- 同 seed 确定性 ❌：训练侧 GPU 浮点不确定（权重 max|Δ|=0.056）经近坍缩空间放大，
  AUROC 重放波动 ±0.01。确定性重跑需换设备，属配方修订。
- 完整数据、判定与诊断见 [followup/STATUS.md](followup/STATUS.md) 与
  [followup/rashomon.md](followup/rashomon.md)；继续收紧需先修订预注册。
